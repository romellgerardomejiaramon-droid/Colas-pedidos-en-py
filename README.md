# Colas pedidos en py

El código implementa un sistema estructurado de gestión de pedidos bajo el principio FIFO utilizando una arquitectura de listas enlazadas que replica un diseño orientado a objetos clásico, comenzando con una interfaz abstracta llamada QueueInterface que establece el contrato obligatorio con los métodos esenciales que toda cola debe poseer para garantizar un comportamiento estándar. Por su parte, la clase Order modela la información individual de cada pedido almacenando los datos del cliente y la cantidad solicitada con métodos propios para retornar sus atributos y mostrar su información formateada, mientras que la clase Node funciona como un eslabón que almacena la información del objeto y una referencia hacia el siguiente nodo. La clase principal Queue hereda de la interfaz y administra toda la lógica mediante los apuntadores top y tail para controlar el inicio y fin de la fila, albergando operaciones fundamentales como enqueue para añadir elementos, dequeue para retirarlos, size para contar iterativamente los nodos, isEmpty para verificar si está vacía, front para consultar el primer elemento, printInfo para generar un volcado legible y getNth para localizar un elemento por su posición numérica. Finalmente, la clase TestQueue actúa como el controlador de pruebas que inicia un registro de tiempo, crea y añade los objetos de tipo pedido, ejecuta las consultas de posición, realiza las extracciones y vuelve a volcar el estado de la estructura para concluir imprimiendo en la terminal el tiempo total transcurrido durante la ejecución de la prueba.
